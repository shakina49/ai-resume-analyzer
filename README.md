# AI Resume Analyzer

A Python application that analyzes resumes against job descriptions to provide a score based on keyword matching and basic NLP logic.

## Project Description
This project automates initial resume screening by:
- Extracting text from resumes
- Matching keywords with job requirements
- Providing a numerical match score

## Features
- Resume text extraction (PDF/DOCX)
- Keyword matching
- Score generation for candidate-job fit
- Streamlit interface for easy use

## Tech Stack
- Python
- Streamlit
- Natural Language Processing (basic)
- PDF/DOCX parsing libraries

## Setup & Installation
1. Clone the repository:
  git clone https://github.com/shakina49/ai-resume-analyzer.git
2. Navigate to the project directory:
  cd ai-resume-analyzer
3. Install dependencies:
  pip install -r requirements.txt
4.Run the application:
  streamlit run app.py
